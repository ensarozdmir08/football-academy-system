Football Academy Performance Tracking System

A web-based application designed to help football academies manage players, record performance data, provide coach feedback, and allow parents to monitor their child's progress.

System Modules

  • Coach Dashboard

  • Reports and Statistics

Project Features

Coach Access

Coaches can manage players, add performance records, update feedback, and review academy statistics.

Parent Access

Parents can view their child's attendance, goals, rating, coach feedback, and performance history.

Performance Tracking

The system stores attendance, goals, ratings, dates, and feedback using a MySQL database.
